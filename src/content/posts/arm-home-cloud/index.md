一台低功耗的 ARM 小主机，硬是被我折腾成了一个随时能访问的私人云盘。回头看，这大概是最近折腾得最完整的一套服务了。

## 从系统到服务

底子是一台 ARM64 的小主机，刷了 Armbian。装好系统之后先上 1Panel 当管理面板，再把 Docker 和 OpenResty 安排上，之后所有服务都用容器跑，统一管理省心。文件分享用的是 FileCodeBox 2.8.3，一个轻量的分享服务，扔文件、生成链接、发给别人，几步就完。

## 内网穿透和 HTTPS

家里宽带没有公网 IP，外面的访问靠 Sakura FRP，配合 frpc 跑在 Docker 容器里做穿透。内网和公网分别走了不同的域名，内网走直连，公网走穿透，互不影响。

HTTPS 这块费了点功夫。用 DNSPod 的 DNS-01 验证去申请 Let's Encrypt 证书，域名解析和证书能一起管。踩坑最多的是证书签发：有一阵子 ACME 反复报错，证书怎么都签不下来，最后发现是之前挂的代理残留没清干净，清了才通。DNS 解析失败这类小问题也碰上过几回。

## 低配机器的折腾

ARM 小主机的内存本来就紧张，几个容器一跑更明显。于是加了 Swap 和 zram，把内存压力缓一缓，又顺手关掉了一些用不到的基础服务。现在整套东西跑起来还挺流畅，没有一开始那种卡卡的感觉。

现在它是一个能远程访问的个人文件服务，内网公网两条路都通，HTTPS 也配好了。回头看，把这台 ARM 小机器盘活的成就感，不亚于攒一台新机器。
