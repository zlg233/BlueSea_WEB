家里那台 Ubuntu 服务器一直有个尴尬：没有公网 IP，人一出门就连不上它了。

想在外面查个东西、传个文件，都得等回到家里才行。折腾了一圈，最后用 frp 给它开了一条专属的 SSH 隧道，这事才算解决。

## 思路

frp 的原理不复杂：有一台有公网 IP 的服务器当中转（frps），内网的机器上跑一个客户端（frpc），主动去连这个中转。之后外面访问中转上的某个端口，流量就会被转回内网机器，等于把内网的服务"借"到了公网上。

我在阿里云那台服务器上跑了 frps 当服务端，内网的 Ubuntu 上跑 frpc，把远程端口映射到本地的 SSH 服务。这样不管人在哪，只要能连上阿里云那台机器，就能顺着隧道登录回内网的 Ubuntu。

## 配置上花心思的几个地方

frpc 和 frps 之间配了 token，两边对不上就连不通，省得隧道被别人白嫖。自启这块用 systemd 把 frpc 注册成服务，开机自启、挂了自动重启，不用每次手动拉起。SSH 端也顺手加固了：只认密钥登录、禁掉密码登录，隧道打通的同时把暴露面收窄。

中间也踩了点小坑：端口和防火墙没对齐的时候，隧道建不起来，查半天才发现是这一处；还有一次是 frps 和 frpc 的 token 不一致，日志反复报认证失败。都是配置对齐的事，改完就顺了。

## 现在

这套跑到现在一直挺稳，出门在外随时能 SSH 回家，跟人在家里操作没什么两样。
